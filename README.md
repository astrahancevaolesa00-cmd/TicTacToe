Руководство пользователя

Данная игра "Крестики - нолики" является интересной и увлекательной игрой.

Поле игры состоит из 9 клеток расположением 3 на 3.Чтобы начать игру ,для начала выберите за какой символ будете играть "X" или "О".

Обычно "Х" ходит первым. Игроки ходят по очереди,занятую клетку изменить уже нельзя.

Цель игры заключается в том ,чтобы одинаковые символы одного из игрока совпали либо по вертикали,либо по горизонтали,либо по диагонали.

Интерфейс:

1. Изначально игровое поле пустое. Ниже игрового поля в строке "Ход" подсвечивается кто из игроков сейчас ходит.
